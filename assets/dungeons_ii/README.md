# Minecraft Dungeons II reference textures

These textures were decoded from the user's installed **Minecraft Dungeons II**
Steam game (app **1912410**) on **2026-10-04**, after the user explicitly
authorized local asset extraction and reuse. They are original game textures,
not textures generated by Sparkle. This provenance records the user's stated
permission; it does not relicense the source artwork under Sparkle's code license.

The installation was read only. CUE4Parse and CUE4Parse-Conversion
`1.2.2.202609`, using the UE5.6 package format and matching Steam type mappings,
decoded the stored texture pixels to PNG. The PNGs are copied without image
editing, resampling or channel changes. No game executable, archive, extraction
utility, profile or decryption metadata is included here.

Sparkle samples the native pixel-noise texture's sparse red channel for small
surface flecks on a 1/16-block scale, the flow texture for streaks on vertical
water faces. The skybox textures are retained as visual references; the active
Dungeons clouds are now generated physical square geometry at the user's request.
The decoded water master references all four water textures. Smooth grayscale
`T_SeamlessClouds` supplies a broad animated field; the seven binary RGB colors
of `T_PixelNoise_Bright` supply finer vector variation. The latter is packed
noise, not an authored normal map. Sparkle constructs a small world-space normal
perturbation from these fields, sampling on one fixed 1/16-block grid before
animation. Geometry remains flat while reflections break into coherent moving
square patches, as in the user's gameplay recording; the smooth field leads and
the binary field only roughens patch edges.
Packed-noise animation interpolates within each fixed square cell, while a
Blender-specific 32–96-block distance fade and grazing-angle attenuation restrain
distant reflection fragments; these are adaptations, not recovered game equations.

Wave strength/speed, broad/fine wave mix, optional see-through amount/tint and reflection strength are independently
editable shader controls. Their defaults, the field combination and Cycles-only
direct-light transmission approximation are Blender adaptations, not recovered
game graph values. They replace an earlier flat five-percent reflection model
that omitted the pixel distortion and translucency visible in the recording.
`cloud_shapes.json` holds footprints rasterized from the game's 16
`SM_Clouds_Shape*` meshes (`Dungeons/Content/Spicewood/Art/Environment/Generic/Nature/Meshes/Clouds/`),
decoded the same way and with the same permission. They are generated by
`tools/build_dungeons_cloud_shapes.py`, one cell per game block. The meshes are
flat one-block slabs, and only their outlines are kept. The even water body color is
`MI_WaterOverworld` Colour Deep.
Sparse and Dense now select layouts of these shapes. Their normalized mesh-height
fade supplies transparent tops; height, thickness, size, tint and motion remain
editable. Neither skybox PNG is sampled by an active cloud world layer. They
remain unchanged reference assets with the provenance and checksums listed above.
Those Blender connections and controls are adaptations. Cooked material caches
preserve parameters and texture references but not the original editable shader
graph, so this is not a verbatim port of the game's complete rendering system.

Local extraction manifests and decoded material properties live under
`test_output/dungeons2_reader/exports` in the development workspace; they are not
part of the release. Broader evidence and implementation limits are documented
in `docs/research/minecraft-water-and-vibrant-visuals.md` in the repository.
