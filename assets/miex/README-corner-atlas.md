# MiEx corner atlas

`corner_atlas.png` is copied unchanged from the bundled MiEx
`v2.0.0.experimental-28` JAR entry (unchanged since experimental-26):

`default_data/base_resource_pack/assets/miex/textures/corner_atlas.png`

Source: https://github.com/BramStoutProductions/MiEx
Copyright Bram Stout Productions; BSD 3-Clause license. See
[`LICENSE-MiEx.txt`](../../exporters/miex/LICENSE-MiEx.txt).

Sparkle uses MiEx's exported `uvCornerST` coordinates to sample this normal map
on reversible, opaque terrain material copies. The normal perturbation and
restrained edge-albedo increase are Blender adaptations of the technique
explained at https://bramstout.nl/en/work/minecraft-live-march-2025/.
